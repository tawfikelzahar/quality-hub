About This Tool

The Tawfik Elzahar SPC Engine is a free, browser-based Statistical Process Control tool built for quality engineers and manufacturing professionals. It supports both Variable Data (I-MR and X̄&R charts) and Attribute Data (p, np, c, u charts), with full Capability Analysis (Cp, Cpk, Pp, Ppk), Nelson Rules violation detection, and Anderson-Darling normality testing — all running locally in your browser with no installation required.

How to Use — Step by Step
1

Select Your Data Type

Choose Variable for measured data (dimensions, weight, pressure) or Attribute for count data (defects, pass/fail).

2

Set Subgroup Size (N)

Use the +/− buttons. N=1 activates I-MR chart. N≥2 activates X̄ & R chart automatically.

3

Enter Specification Limits

Enter LSL and USL if available. Required for Cp, Cpk, Pp, Ppk capability analysis.

4

Enter Your Data

Type directly or paste from Excel using Tab between columns and Enter between rows.

5

Click ANALYZE

Instantly generates control charts, capability indices, sigma level, and Nelson violations.

6

Export Your Results

Use Export to Excel for a 3-sheet report, or Print/PDF for a printable version.
